# Triage labels

| Role | Label | Meaning |
|---|---|---|
| Needs triage | `needs-triage` | Newly reported work awaiting classification and duplicate search. |
| Needs information | `needs-info` | Required facts or reproduction details are missing. |
| Ready for agent | `ready-for-agent` | Scope and acceptance criteria are concrete enough for implementation. |
| Ready for human | `ready-for-human` | Requires a human decision, authorization, credential, legal review, or production action. |
| Won't fix | `wontfix` | Intentionally not planned; rationale must be documented. |

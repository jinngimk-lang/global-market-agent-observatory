# Issue tracker

## System

GitHub Issues in `jinngimk-lang/global-market-agent-observatory` are the source of truth for planned work, defects, research follow-ups, and production-readiness gates.

## Workflow

- Search existing open and closed issues before creating a new one.
- Use one issue per independently verifiable outcome.
- Link implementation commits and pull requests to the issue.
- Keep acceptance criteria observable through public interfaces, tests, logs, or documented artifacts.
- Pull requests are not automatically treated as new triage requests.

## Safety-sensitive work

Any change that can place, amend, cancel, transfer, withdraw, or expose credentials must be isolated in its own issue and pull request, include a threat model, and remain disabled by default.
